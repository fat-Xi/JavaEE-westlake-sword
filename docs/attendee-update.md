# 参会者原型落地交接（2026-11-13）

## 修改位置与范围

代码在桌面 westlake-sword。只重做参会者界面及共用登录注册页；管理员、展商和工作人员组件未改版。需求 Word、汇报 PPT、独立原型均未修改。改动前源码归档在 backups/before-attendee-*.zip。

## 已落地

- 紫色与青色清新界面，活动轮播、状态筛选、关键词搜索、推荐/热度/时间排序；筛选仅刷新活动列表动画。
- 会议首屏轮播、居中的功能导航及右侧报名/签到；未通过报名只见基本详情，未开始会议仅显示详情、议程、展商内容。
- 直播回放独立栏目，真实媒体内嵌、关闭和未发布提示；议程添加/移除个人日程、后端冲突校验、复制分享链接。
- 提问、评论、签名独立滚动内容区和固定编辑区。评论支持议程标签和单选评价；签名支持匿名、字体。评论签名均进原有管理员审核队列，不把原型模拟审核当真实审核。
- 匿名签名公开接口删除 user_id 并隐藏头像网名；后台仍可追溯作者。个人主页可查询本人所有审核状态、定位原文、删除本人评论签名。
- 参会者投票独立组件；多题统一提交，后端事务防止部分成功。发布者仍为管理员，本次未改变其他角色权限。
- 签到弹窗使用真实个人凭证，工作人员核销，参会者不能自行伪造已签到。未到签到时间不展示取码按钮。
- 登录、注册、退出及身份审核提示继续走原接口。其他角色仍使用原界面。

## AI 复用

AiApi、AiKnowledge、AiModelClient、AiParticipant 及其 25 项专项测试来自组员 feat/hanlei-ai 分支 d555159。保留真实 API、引用、资料检索降级、并发控制、取消请求、会话失效和报名权限复核。适配原项目未有 featured 字段的 SQL，修正规则文本中的栏目名称及尚未移植的赞同功能描述。没有搬入其他角色界面。

前端使用 /api/ai/events 与 /api/ai/ask。后台直接查询个人/公开记录；模型不可用时明确标注检索结果。当前每次问题独立检索，不发送历史上下文，不模拟逐字生成。消息区独立滚动，发送不滚动整页。

AI 配置在 Git 忽略的 .env.ai.local（从本机组员配置提取 AI_* 项），只由后端读取。不要提交密钥。启动脚本自动加载；普通 java 命令需自行设置 AI_BASE_URL、AI_MODEL、AI_API_KEY、AI_TIMEOUT_SECONDS。

```powershell
powershell -ExecutionPolicy Bypass -File .\start-attendee.ps1 server
powershell -ExecutionPolicy Bypass -File .\start-attendee.ps1 web
```

## 按钮对齐与AI逐字动画
