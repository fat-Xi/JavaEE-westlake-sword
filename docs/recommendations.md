# 个性化议程推荐

参会者在会议详情的“会议议程”页查看推荐。推荐使用现有兴趣标签、议程标签及个人日程，无新增表或字段。

`GET /api/events/{id}/recommend` 仅允许身份及该会议报名均审核通过的参会者调用，会议须处于 OPEN 状态。

## 推荐规则

1. 仅推荐当前会议未结束、本人尚未加入日程的议程。
2. 兴趣标签和议程标签按逗号、分号、顿号或空白分隔；统一全角字符、忽略英文大小写并去重，采用完整标签匹配。
3. 检查全部个人日程，覆盖跨会议的时间冲突。时间区间首尾相接不视为冲突，与现有加入日程接口一致。
4. 先排无冲突的议程，再按匹配标签数降序、实际收藏人数降序、开始时间升序和 ID 升序排列，最多返回 6 项。
5. 无兴趣或无标签匹配时，使用真实收藏人数排序；无人收藏时按开始时间排序。冲突议程有明确提示，页面禁用加入按钮，后端原有冲突校验仍生效。

## 接口与页面

保留议程基本信息、`score`、`popularity`、`reason`。新增 `matched_tags`（匹配的兴趣标签列表）和 `conflicts`（冲突日程的 ID、会议 ID/标题、议程标题、会场、起止时间）。响应不包含直播或回放地址。

页面显示议程时间、嘉宾、会场、具体推荐理由及冲突详情。支持手动刷新、加载失败重试和空状态；从议程列表或推荐中加入日程后，推荐自动更新。

当前版本采用标签规则与真实收藏热度；浏览行为、岗位画像和模型推荐尚未接入。

## 验证

用报名已通过的参会者登录，在会议详情的「会议议程」查看推荐，把推荐议程加入日程后可查看推荐是否实时更新。用时间重叠的跨会议议程验证冲突提示。
