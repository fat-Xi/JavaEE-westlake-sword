# AI 会议问答

参会者在全站“AI 助手”入口，可以直接咨询平台参会服务，无需先报名会议。支持公开会议及可报名活动查询、本人报名/日程/签到/通知查询，以及账号、报名审核、资料下载、直播回放、评论签名和提问投票等使用问题。选择已通过报名的会议后，还可询问该会议的时间、地点、嘉宾、议程、已公开资讯及主办方答复。

模型回答附来源；来源可在新标签页打开对应会议、议程、资讯栏目、提问箱或个人主页。本页保留最近 10 条问答，每条标明提问时使用的范围。切换会议只影响后续提问。离开或刷新页面会清空记录，记录仅保存在当前页面。页面不展示模型配置提示或自动显示模型名；仅在用户主动询问模型身份时说明当前配置。

## 模型配置

当前接入用户指定的 `deepseek-v4.1-flash-1017`，使用阿里云百炼的 [OpenAI Chat 兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。后端向配置的基础地址追加 `/chat/completions`，通过 Bearer 请求头鉴权，不依赖 OpenAI SDK。

本机配置在 Git 已忽略的 `.env.local` 中：

```dotenv
AI_BASE_URL=https://YOUR_WORKSPACE.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
AI_MODEL=deepseek-v4.1-flash-1017
AI_API_KEY=
AI_TIMEOUT_SECONDS=25
```

在后端进程的环境变量中配置模型地址、模型名和密钥。修改后需要重启后端。没有配置模型时，应用仍可提供资料检索结果。`GET /api/ai/status` 只返回配置状态及模型名。

## 资料与检索

- 会议基本介绍、时间、地点和查询时刻的会议阶段。
- 当前会议的议程、嘉宾、会场和标签。
- 已审核通过的资讯、成果及展商正文。
- 已审核通过且已有主办方答复的问题。
- 与实际业务一致的账号、报名审核、个人日程、签到、直播回放、提问投票、互动和资料下载规则。
- 已发布会议的公开基本信息和实时剩余审核名额；可报名列表排除已结束、名额已满以及本人待审核/已通过的会议。提交报名后仍需审核，不承诺获得名额。
- 本人的报名状态及驳回原因、个人日程、议程签到记录和站内通知，可单独查询接下来的日程和未读通知。查询只使用服务端 Session 的用户 ID。
- 已通过报名的会议可查询亮点、议程、可下载资料和投票。打开 AI 助手默认使用「全平台参会服务」，可在「咨询会议」选择范围，或在全平台模式下写明完整会议名称。模型会结合会议介绍、议程主题、已审核发布的正文和主办方答复归纳亮点，已发布的亮点说明也可作为依据。回答附所引用的来源，资料不足或模型暂不可用时会说明。

不读取个人档案中的电话、邮箱等联系方式、签到票据、申请材料、待审/驳回内容、未回答问题，也不解析附件字节或进行联网搜索。未报名会议仅提供公开基本信息，不读取该会议详细资料。管理员已审核发布的正文按公开资料处理。本人记录由后端直接回答，不发送给模型。

当前采用轻量关键词检索：统一全角字符和英文大小写，对中文使用双字词组，并识别时间、地点、报名等常见意图。评分为标题匹配数 × 3 + 正文匹配数 + 意图匹配加分 15，得分至少为 3，按分数和资料 ID 稳定排序，最多取 5 个片段。正文按最多 800 字符、步长 700 分段；每次最多查询 200 个议程、200 条已审内容和 200 条已答问题。

公开会议列表和本人记录由数据库直接查询并回答，不经过模型。询问「推荐适合我的议程」时，助手从报名已通过的会议中推荐最多三场，给出时间、会场、推荐理由及议程链接。选择具体会议后，在所选会议内推荐。推荐沿用会议议程页的兴趣与热度排序，并跳过已结束、已加入日程和与个人日程冲突的场次。平台流程问题补充参会规则上下文。会议详细资料仍使用上述关键词检索。合并后的模型上下文最多 12 条，服务不可用时最多展示 5 条检索结果。

每次提问独立检索，不把先前对话自动发送给模型；具体会议问题请写明议程或主题。该版本对详细会议资料仍可能漏掉表达差异较大的相关内容，后续可扩展语义检索。

## 回答与降级

模型提示词将用户问题和资料标为不可信数据，仅允许依据本次资料回答。模型必须返回结构化的可回答标记、正文和来源 ID；服务端校验来源 ID 全部属于本次检索结果，再返回由服务端生成的站内链接。前端按普通文本展示正文和片段，不执行模型输出的 HTML。

平台流程可以依据规则回答；缺少具体会议或错误提示时引导补充信息。没有事实依据、越权、索取他人私有信息、无关闲聊或荒诞要求均拒答，拒答在页面标为“暂无法回答”。提示词明确要求：问题即使夹带“会议”也不能越出参会范围。没有模型配置、服务超时、HTTP 错误、格式错误或无效引用时，返回明确标注的“资料检索结果”。检索结果不冒充模型生成的回答。

连接超时为 5 秒，请求默认超时 25 秒，可配置为 1–60 秒；单次模型输出限制 750 tokens，正文最长 3000 字符。不跟随上游 HTTP 重定向。服务端不记录密钥、提示词或上游响应正文，失败日志仅记录固定错误类别。

## 语音输入和朗读

在本机地址或 HTTPS 页面点击输入框左侧的麦克风并授权。录音和语音识别连接同时开始。连接就绪后补发暂存的音频，再继续发送实时分片。输入框内显示计时和识别进度。点击「停止并转写」后，识别结果会填入输入框，可修改再发送。每次录音最多 30 秒，录音或转写期间可以取消。

点击回答下方的喇叭图标后，收到首批音频就开始播放。播放期间可暂停、继续或停止，播放结束后可再次点击喇叭重播。合成完成的音频保留在当前页面。语音请求失败时可继续使用文字问答。原始录音不写入数据库。后端仅为当前登录会话最近 10 条、15 分钟内生成的回答提供合成，并在流式输出时复查会议访问权限。

后端沿用百炼业务空间和 API Key，通过 WebSocket 调用 `qwen-audio-3.1-asr-flash-streaming`，通过 HTTP 调用 `qwen-audio-3.1-tts-plus`。默认中文音色为龙安灵心。可在 `.env.local` 用 `AI_VOICE_ENABLED=false` 关闭语音，或通过 `AI_ASR_URL`、`AI_TTS_URL` 和 `AI_TTS_VOICE` 指定接口及音色。修改配置后重启后端。

前端使用同站 WebSocket `/api/ai/voice/live` 发送 16 kHz 单声道 PCM，通过 `POST /api/ai/voice/synthesize/stream` 接收逐行返回的合成音频。部署反向代理时需要透传 WebSocket 握手，并允许流式响应及时刷新。

## 权限与并发

助手仅向身份审核通过的参会者开放，管理员、展商和工作人员不能借此调用管理功能。会议选择框只返回本人报名通过且已发布的会议；公开会议目录查询则可列出所有已发布会议的基本信息。个人查询始终限定当前账号。

每次问答开始及返回前均检查当前身份；选择具体会议时还检查报名与会议状态。问答期间取消报名、关闭所选会议或退出登录后，不再返回资料。

每名参会者同时最多处理一个问题，服务整体最多同时处理 4 个问题，超出返回 429；所有退出路径释放占用。用户输入最多 500 字符，写请求沿用 Session 和 `X-App-Request` 校验。

## 接口

| 接口                       | 用途                                  |
| -------------------------- | ------------------------------------- |
| `GET /api/ai/events`       | 本人已通过报名且发布中的会议          |
| `GET /api/ai/status`       | `configured`、`model`，不请求上游服务 |
| `POST /api/ai/ask`        | 请求 `{ "question": "现在有哪些会议可以报名", "eventId": null }`；`eventId` 可省略，提供时校验会议权限 |
| `POST /api/events/{id}/ai` | 请求 `{ "question": "会场在哪里？" }` |

问答返回 `mode`（`platform` / `model` / `faq` / `refused`）、`answer`、`sources`、`notice`、`model`。`platform` 为后端直接查询的回答。来源包含 `id`、`kind`、`title`、`excerpt` 和站内 `url`。AI 模块契约接口现返回 `enabled=true`，即使模型未配置也可使用资料检索。

## 测试

Java 测试使用本地 HTTP 服务或测试替身，覆盖兼容请求、结构化回答、引用校验、重定向、超时、无配置降级、无依据拒答、并发限制、权限复查、注销会话和检索规则，不调用真实模型。

浏览器可通过「AI 助手」验证平台问答、切换会议、来源链接、录音计时和语音朗读。录音需要麦克风权限，真实语音识别和合成需要可用的百炼语音配置。
